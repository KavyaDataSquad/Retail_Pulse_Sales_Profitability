# Retail Pulse | Sales & Profitability

An end-to-end retail analytics portfolio project using the included Superstore dataset. The repository combines SQL analysis, Python EDA, Excel assets, and Power BI report files.

## Business questions
- Which categories and regions contribute most to sales and profit?
- How do customer segments and products perform?
- Where do discounting and shipping patterns deserve closer review?
- How do monthly sales trends change over time?

## Included assets
- `Power BI/`: Power BI Desktop report (`.pbix`), dashboard preview images, and walkthrough video.
- `SQL_Analysis/`: validation, KPI, ranking, profitability, and trend queries.
- `Python/`: notebook and supporting datasets.
- `Excel/` and `Dataset/`: source and cleaned data files.
- `Reports/Retail_Performance_Analysis.md`: dataset-derived KPI and category/region summary.

## Dataset snapshot
- 9,994 rows | 5,009 distinct orders | 793 distinct customers
- Sales: **$2,297,200.86** | Profit: **$286,397.02** | Profit margin: **12.47%**

## How to explore
1. Load the cleaned dataset into MySQL using the included SQL script (adjust table/database names to your environment).
2. Open the Python notebook and run cells in order.
3. Open `Power BI/Retail_Sales_Dashboard.pbix` in Power BI Desktop and refresh the data source path if prompted.
4. Review the report images and the analysis notes in `Reports/`.

## Skills demonstrated
SQL (CTEs, window functions, aggregations, CASE, views), Power Query, DAX, data modelling, Python/Pandas, KPI design, business analysis, dashboard storytelling.
